Bienvenue chez Logos ! Nous sommes ravis de vous accueillir pour façonner ensemble le web décentralisé. Que vous soyez développeur, rédacteur, designer ou que vous disposiez d’autres compétences précieuses, il existe de nombreuses façons de vous impliquer et d’avoir un impact.

Pour commencer, vous pouvez soumettre vos idées ou projets via le [formulaire de proposition](/proposals).

Vous pouvez également consulter des guides adaptés expliquant comment contribuer en fonction de vos compétences :

- [Contribuer à des initiatives locales de terrain](/resources/activists)
- [Pour les développeurs](/resources/developers)
- [Pour les rédacteurs](/resources/writers)
- [Pour les organisateurs d’événements](/resources/event-organisers)
- [Pour les traducteurs](/resources/translators)
- [Pour les designers](/resources/designers)
